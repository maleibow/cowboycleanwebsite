Drop the game's music files here (MP3 or OGG, 128 kbps, loudness-normalised, ~3 MB each).
The file names must match the `file` fields in game3d/data/music.js (default: title.mp3, stage01.mp3 ... stage10.mp3,
boss.mp3, saloon.mp3). A slot with no file plays procedural synth music instead. Files are streamed on demand.
